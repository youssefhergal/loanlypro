## Prochaines étapes

1. **Capturer les écrans** sur [pfr-dev.web.app](https://pfr-dev.web.app) en suivant la checklist.
2. **Enregistrer** les PNG dans `assets/images/commun|client|conseiller|admin/`.
3. **Relire** le guide : les images s'afficheront automatiquement si les noms correspondent.
4. *(Optionnel)* Exporter en PDF via VS Code, Pandoc ou GitLab Pages.

## Conseils rédaction

- Rester **orienté action** (« Cliquez sur… », « Renseignez… »).
- Éviter le jargon technique (API, JWT, Cloud Run…).
- Une **légende** sous chaque image (« Figure N — … »).
- Garder les **mêmes comptes seed** pour la cohérence visuelle.
